# WebCity frontend

The Angular app for WebCity. Start the [backend](../README.md#running-it) first. Check the Node version in the [frontend development guide](CLAUDE.md#commands), then run these commands from `frontend/`.

```bash
npm ci
npm start
```

Open <http://localhost:4200>. For password reset and reactivation links, see the [allowed-origins setting](../CLAUDE.md#architecture).
